# ECHOES: The Lost Signal

*Explore. Discover. Survive. Escape.*

## About the Game

ECHOES: The Lost Signal is a science-fiction exploration and survival
game set on an unknown alien planet.

After a spaceship crash leaves the player stranded, the main objective
is to explore the planet, collect the resources required to repair the
damaged spacecraft, and find a way to escape.

Players are equipped with a special scanner that reveals hidden areas
and elements of the environment that would otherwise remain invisible.
By activating the scanner, players can discover new paths, uncover
resources, and expose previously hidden enemies.

However, exploration is not without danger. Hostile creatures inhabit
the planet and can damage the player, making exploration and resource
collection an important part of survival.

The ultimate goal is to gather all the necessary materials, repair the
spaceship, and escape the planet.

## Gameplay Features

-   **Planet Exploration:** Explore an unfamiliar alien environment and
    discover new locations.
-   **Scanner Mechanic:** Activate a special scanner to reveal hidden
    areas and objects that cannot normally be seen.
-   **Resource Collection:** Search the planet for materials needed to
    repair the spaceship.
-   **Hostile Enemies:** Encounter creatures that can damage the player.
-   **Survival and Strategy:** Explore carefully while managing
    encounters with enemies.
-   **Main Objective:** Collect the required resources, repair the
    spaceship, and escape.

## Requirements

To run the game, you will need:

-   A computer running Windows, macOS, or Linux.
-   Godot Engine 4.7.2.
-   The game project downloaded from the GitHub repository.

No additional game development software is required to run the project.

## Installation and Setup

1.  Download or clone the game repository from GitHub.
2.  Install Godot Engine 4.7.2.
3.  Open Godot Engine.
4.  Select **Import** in the Project Manager.
5.  Navigate to the downloaded project folder.
6.  Select the `project.godot` file.
7.  Open the project.

The project will now be available in the Godot Editor.

## How to Run the Game

Once the project is open in Godot:

1.  Press **F5** to run the main project.
2.  Alternatively, press **F6** to run the currently selected scene.
3.  The game will open in a preview window.

No separate build is required to test or preview the game inside Godot.

## Exporting the Game

If you want to create a standalone playable version:

1.  Open the project in Godot Engine.
2.  Navigate to **Project → Export**.
3.  Select the desired export platform.
4.  Install the corresponding export templates if prompted.
5.  Select **Export Project**.
6.  Choose the destination folder for the exported game.

The exported version can then be distributed and played without opening
the Godot Editor.
